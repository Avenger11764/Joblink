# JobLink

A modern, fully responsive job matching portal and application wizard built with React, TypeScript, and Tailwind CSS. JobLink simplifies recruitment and application workflows with an elegant, responsive interface.

## Features

- **Interactive Landing Page**: Easing numerical counters, smooth scroll effects, responsive carousel sliders, and built-in contact channels.
- **Job Search Hub**: Real-time filtering and search queries for open roles.
- **6-Step Application Wizard**: Streamlined resume builder that breaks complex forms into step-by-step components.
- **Draft Auto-Save**: Progress is saved automatically to localStorage so users never lose their application data.
- **Recruiter Portal**: Material Design Bento-grid statistics panel for posting jobs and managing incoming candidates.
- **Fully Responsive**: Adaptive horizontal navigation scroll for mobile viewports and clean layout scaling across devices.

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Icons**: Lucide React, Google Material Symbols
- **Build Tool**: Vite

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Avenger11764/Joblink.git
   cd Joblink
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
